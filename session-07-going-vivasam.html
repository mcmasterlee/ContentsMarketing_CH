Presentation Record 07

2026년 비바샘이 간다 대시보드

발표 기록

김연희 CP

흩어진 일정·보고서·이슈 관리를 하나의 대시보드로 통합하고, 현장 의견의 개선 이력까지 추적할 수 있도록 만든 실무형 개선 사례.

‘비바샘이 간다’ 운영 과정에서 팀즈와 셰어포인트에 나뉘어 있던 정보를 한 화면에 모았습니다. 비개발자가 바이브코딩으로 직접 구현해 확인 단계를 줄이고, 현장 의견이 실제 개선으로 이어지는 과정을 추적 가능하게 만든 프로젝트입니다.

대시보드 바로가기

발표 내용 재구성

01

‘비바샘이 간다’란

신청 선생님의 학교를 직접 방문하거나 비대면 프로그램을 통해 비바샘 서비스와 비상교과서를 소개·홍보하는 간담회입니다.

02

기존 운영 방식의 한계

일정은 팀즈 채널 게시물과 공유 파일로, 결과 보고서는 셰어포인트 폴더로 관리했습니다. 핵심 이슈를 확인하려면 보고서를 각각 열어야 했고, 서비스와 콘텐츠의 개선 이력이나 진행 상황을 한곳에서 확인하기 어려웠습니다.

03

대시보드 개발 목적

흩어진 일정·보고서·이슈 데이터를 한곳에 모아 확인 단계를 줄이고, 현장 의견이 실제 개선으로 이어지는 과정을 추적 가능하게 만드는 것을 목표로 했습니다.

04

바이브코딩으로 직접 제작

별도의 개발 리소스 없이 바이브코딩을 활용해 대시보드 페이지를 직접 구현했습니다. 기획자가 아이디어를 실제 작동하는 페이지로 옮긴 실무 사례입니다.

05

주요 기능

일정과 학교 방문 현황, 지역별 방문 현황, 주요 이슈, 이슈별 조치 현황, 보고서 아카이브, 2023~2025년 히스토리를 한 화면에서 확인할 수 있습니다.

하이라이트

교사 의견 → 개선 이력으로 추적 가능

핵심 포인트

  • 팀즈·셰어포인트 기반 관리에서 발생한 확인 비효율 개선
  • 별도 개발 리소스 없이 실제 작동하는 운영 페이지 완성
  • 확인의 불편함과 개선 이력 부재를 기능 설계로 해결

  2. 교사 의견 반영 이력의 가시화가 서비스 개선 속도에 어떤 영향을 주었는가?
